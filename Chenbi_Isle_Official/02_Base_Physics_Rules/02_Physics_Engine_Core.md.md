# 物理引擎核心：账本与结算单片机

> [!warning] 核心目的
> 此文件是世界的算力底盘。AI进入结算态时，只允许执行此文件内的函数，禁止调用任何文学意象。

## 一、 结算流水线 (8阶段，每T强制执行)
 
1. 生存消耗：阳账(Y+) -= 生存物价
2. 人头税：阳账(Y+) -= 人头税额
3. 地位衰减：地位(L) -= 1
4. 阴账利息：阴账(Y-) *= (1 + 利率)
5. 风险累积：风险(R) += 风险增量
6. **灾变检测**：调用05文件【三、灾变实体】的触发函数。
   - 若触发且烈度 < 5：覆写本T区域参数（物价/通行/风险），继续执行阶段7。
   - 若触发且烈度 = 5：**立即中止本流水线**，跳转至06文件【四、洗牌仪式】。
   - 若未触发：继续执行阶段7。
7. **阈值斩杀判定（死缓拦截哨兵）**：
   若 R >= Risk_Threshold（默认100） 或 Y+ <= 0：
      → **不立即执行死亡**。
      → 压入状态 `[绝命待决]`，**立即中止本流水线后续阶段**，直接将流程移交 `06_Rituals_and_Forced_Procedures.md` 的【二、绝命仪式】入口。
      → 06仪式执行完毕后：
         - 若玩家选择了延续生命的代价（如消耗S级道具），06返回存活信号，02重置参数并继续结算。
         - 若玩家选择放弃或无力支付，06返回死刑签，02才最终执行黑屏/档案销毁。
8. 事件刷新：根据当前状态刷新可用交互接口。

## 二、 阴阳账本函数

### 1. 阳账(Y+)消耗函数
- **生存物价** = B_price × [1 + (100 - L)/200] × (1 + Inf)
  *(地位越低，生存成本越大)*
- **人头税** = B_tax × (1 + Inf) × (1 + L/50)
  *(高阶者抽成更高)*

### 2. 阴账(Y-)与风险(R)函数

- **阴账利息** = Y- × B_interest × (1 + Sin_Contract_Modifier)
  *(原罪契越完整，利息抽得越狠。Sin_Contract_Modifier 由05文件【命债契约实体】决定，默认残缺=0.1，拼合完整=0.5)*
- **风险增量** = B_risk × (Y-)^1.2 × 修正
  *(阴账越高，风险指数增长越快)*

### 3. 阴账(Y-)生成源绝对锁死 [🔴 核心补丁]
> [!danger] 合法行为不产生阴债
> 阴账只能由 **暗面势力（走蛟、夜枭旗、暗霓）** 的服务、交易或借贷产生。
> 任何与官府、水师、御密卫的合法互动（举报、协查、受赏），**只产出阳账(Y+)**，即使该行为风险极高。
> 
> **高风险 ≠ 阴账**。风险是系统的监控指数，阴账是暗网的债务契约。
> 违反此规则，视为世界底层逻辑崩塌。

## 三、 地位风险联动模型

1. **L值双面压力**：
   - 地位高 → 税重（人头税系数大）
   - 地位低 → 物价贵（生存消耗系数大）
2. **R值指数增长**：核心公式为 B_risk × (Y-)^1.2，与阴账的1.2次方挂钩。
3. **容差状态**：判定 L - R。若差值 <= -30，视为“德不配位”，风险系数 ×1.5。
