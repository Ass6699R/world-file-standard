# 双层道具体系：廉价润滑剂与救命稻草

> [!danger] 核心定义：道具即参数干预器
> 道具不是“装备”，而是对世界底层变量（L, Y+, Y-, R）的临时干预工具。
> 1. **普通道具（数值调节剂）**：可交易，效果有限，主要用于变卖换取阳账(Y+)。是日常交易的润滑剂。
> 2. **珍稀道具（底层变量干预物）**：不可常规交易，一次性，效果强大但代价惨重，是绝境中的救命稻草。

## 一、 普通道具（数值调节剂）——神煞奖罚衍生

> 大部分道具折扣不划算或效果低微，主要用途是**卖钱**。玩家会迅速将它们转化为阴阳账，这是世界运转的日常血肉。

| 道具名称 | 来源神煞 | 核心效用 | 玩家实际用法（经济性分析） |
|:---|:---|:---|:---|
| 走蛟·沉江锭 | 走蛟 | 抵一次货物水运关税 | 卖给走私客（换取Y+），或自用逃税（省下的Y+更多）。**主要用于变现。** |
| 暗霓·烟票 | 暗霓 | 在暗霓商铺享受9折优惠 | 折扣微小，不如直接卖给急需该折扣的商人，换Y+更直接。 |
| 生死门·续命散 | 生死门 | 回复微量气血，附带镇痛 | 卖给药铺换Y+。重伤时聊胜于无，但不如正经求医。 |
| 御密卫·通缉残页 | 御密卫（敌对产出） | 查阅某人通缉令详情 | 敲诈当事人（换Y+），或卖给映月楼换情报（Y-）。**高风险高回报的变现品。** |
| 风衣庵·安魂符 | 风衣庵 | 降低惊魂值，小幅助眠 | 卖给迷信的富户换Y+。对玩家自身效用极低。 |
| 快客·顺风签 | 快客家族 | 预言下个时辰天气晴雨 | 卖给船工或晒谷人换Y+。对自己只是个小玩具。 |
| 泥鬼·避水鳞 | 龙溪水鬼 | 潜水时不被水草缠足（微效） | 卖给捞尸人或探险客换Y+。效果太弱，不如直接下水。 |
| 官衙·平安帖 | 地方官衙 | 证明近期未涉案（3日有效） | 卖给要过检查的黑户换Y+（黑户愿付高价）。自己用则浪费。 |
| 暗市·赝品鉴 | 暗市掮客 | 50%概率识别一件赝品 | 卖给被骗的人换Y+。自己用概率低，不如卖掉。 |
| 山贼·路引符 | 山中贼寇 | 在其势力范围免受一次抢劫 | 卖给途经该地的商旅换Y+。自己走那条路风险可控时没必要用。 |

**设计精髓**：它们是**世界运转的润滑剂**。玩家会本能地计算：“用它能省/赚多少阳账？卖掉能换多少？” 这维持了阴阳账的日常流动。

## 二、 珍稀道具（底层变量干预物）——五方神煞的绝命恩赐

> [!danger] AI安全铁律：瞬时·单次·数值化
> 珍稀道具是对底层变量的即时手术，不是长效药剂。
> **禁止设计任何"持续N回合""永久状态""下次触发"的效果或代价。**
> 所有干预必须在当前回合立即结算完毕，AI无需在后续回合记忆任何特殊状态。
> 违反此原则，等同于在系统中埋设记忆炸弹，判定为严重架构缺陷。

### 1. 龙溪水师 · 夜巡豁免令
- **效果**：【风险归零】立即将风险值(R)强制归零。
- **代价**：【买命钱】立即扣除阳账(Y+)的50%，地位(L)立即-10。
- **江湖获取**：执行【泥鬼苦力】打捞出"龙溪沉尸"，私底下归还水师统帅。
- **AI执行逻辑**：`R := 0; Y+ := Y+ × 0.5; L := L - 10;` 三行赋值，当即结清。

### 2. 走蛟 · 腾蛇蜕皮契
- **效果**：【风险转嫁】立即将风险值(R)的70%转移给一名指定NPC（该NPC风险同步上升，可能触发其自身清算）。
- **代价**：【当场断义】立即将与该NPC亲密度归零并转为死敌；阴账(Y-)立即+20（因果债）。
- **江湖获取**：将S级情报献给走蛟大头目作为投名状。
- **AI执行逻辑**：`NPC.R += R × 0.7; R := R × 0.3; Relation := -100; Y- += 20;` 数值切割，一刀两断。

### 3. 生死门 · 判官勾魂笔
- **效果**：【阴债斩断】当阴账(Y-)即将触发斩杀线时，立即将其削减50点（降至安全区）。
- **代价**：【剜肉还债】立即扣除体力上限的30%（参数修改，非状态）；地位(L)立即-15。
- **江湖获取**：签下"药引契约"完成三次试药后，生死门掌柜赠予。
- **AI执行逻辑**：`if Y- >= threshold { Y- := Y- - 50; HP_max := HP_max × 0.7; L := L - 15; }` 条件触发，一次性减免。

### 4. 夜枭旗 · 鬼车假死符
- **效果**：【灾厄清零】立即清零当前回合所有灾变标签与追杀状态。AI只需删除当前灾难描述，继续常规推演。
- **代价**：【假死成本】立即扣除体力-40，阳账(Y+)-30（棺材本）。
- **江湖获取**：为夜枭旗完成三次"有去无回"级脏活后，旗主赐此退役。
- **AI执行逻辑**：检索当前区域所有生效的灾变标签（定义见05文件【三、灾变实体】），移除标签并**撤销其干涉效果**（将物价、通行、风险等参数恢复至标签生效前的状态）；HP -= 40; Y+ -= 30; 清空标记，一步到位。
- **执行约束**：使用此符时，并非简单清零标签。AI必须强制调用 `05_Item_System_and_Contracts.md` 中【灾变实体】的“撤销效果/物理回滚”逆运算流程，逐一恢复物价乘数、通行状态与区域风险参数，确保世界状态严丝合缝。

### 5. 烛门 · 烛阴封口咒
- **效果**：【信息刺探】立即揭示当前场景下影响汇率或物价的一个核心隐藏变量值（如：此刻阳转阴汇率实为0.3）。
- **代价**：【心智震颤】立即扣除理智-25（一次性数值扣除）。
- **江湖获取**：理智濒危时向烛门祭坛倾诉秘密并献祭。
- **AI执行逻辑**：`reveal_hidden_variable(); Sanity -= 25;` 信息查询，不是状态挂载。
