> ⚠️ **重要声明：本仓库仅开源世界文件创作框架，不包含《沉璧屿》(Chenbi Isle) 的任何内容。《沉璧屿》作为官方标杆作品，将通过官方渠道单独发布，保留所有权利。**

## 🌍 这是什么？
`world-file-standard` 是全球首个**纯文本、零代码、跨大模型**的AI互动叙事创作框架。它解决了当前所有AI游戏/跑团/互动小说的核心痛点：人设崩坏、规则混乱、模型依赖、无法移植。

你不需要懂编程，不需要租服务器，只需要会写Markdown，就能用这套框架搭建一个自洽、稳定、可在任何支持知识库的AI上运行的完整世界。

**核心理念：世界不是写出来的，是算出来的。用规则铸造牢笼，用故事填满血肉。**

## ✨ 核心特性
- 📂 **标准化目录结构**：适配LLM注意力U型分布，最大化规则检索命中率
- 🛡️ **顶层元指令系统**：宪法级规则优先级，从根源解决规则冲突与格式漂移
- 📝 **防崩坏格式模具**：统一输出模板，内置防幻觉、防泄底、防OOC通用规则
- 🔄 **跨模型原生兼容**：一套文件可运行在智谱/Deepseek/Kimi/GPT等所有主流模型
- 🏝️ **开箱即用示例**：包含完整可运行的"无名岛"极简世界，3分钟上手创作

## 🚀 快速开始
1. 克隆或下载本仓库
2. 阅读 `00_框架规范/` 掌握规则编写方法
3. 运行 `99_示例世界_无名岛/` 体验完整流程
4. 复制模板，开始构建你自己的世界
